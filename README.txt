PATRICK WILSON INSURANCE — WEB APP PROTOTYPE

Files:
- index.html: responsive, mobile-friendly static web app prototype.

Features:
- Home and auto quote request paths
- Call/text links for 479-305-3739
- Existing-customer callback request
- Consent checkboxes
- FAQ accordion
- Referral/share action
- Navy and gold theme
- No database and no server-side storage

Important behavior:
Form submissions create a prefilled SMS message addressed to Patrick. The visitor must review and send the message. No form data is posted to a server by this prototype. SMS prefill behavior varies by device/browser.

FREE DEPLOYMENT OPTION: GITHUB PAGES
1. Sign in or create a GitHub account.
2. Create a new public repository, e.g. patrick-wilson-insurance.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish and use the URL shown in Settings > Pages.
8. Test all forms on an actual phone before sharing the link.
